# Configuration

`--config` selects JSON with schema `prompt-translation/v1`. The default is
`PROMPT_TRANSLATION_CONFIG`, otherwise
`${XDG_CONFIG_HOME:-$HOME/.config}/prompt-translation/config.json`.

```json
{
  "schema": "prompt-translation/v1",
  "repository_root": "$HOME/work/records",
  "source_directory": "sources/prompts",
  "output_directory": "learning/pairs",
  "cheatsheet_path": "learning/cheatsheet.md",
  "models": {
    "translate": "caller-selected-translator",
    "classify": "caller-selected-classifier"
  },
  "api": {
    "base_url": "https://model.example.invalid/anthropic",
    "credential": {
      "file": "$HOME/.config/example/model-credential.json",
      "json_key": "api_key",
      "environment": "EXAMPLE_TRANSLATION_KEY",
      "kind": "example-provider"
    },
    "required": true,
    "timeout": 600,
    "max_retries": 2
  },
  "pipeline_revision": 2,
  "filters": {
    "min_chars": 30,
    "max_chars": 2000,
    "min_chinese_ratio": 0.1
  }
}
```

The sample endpoint and model identifiers are placeholders. The configured
service must support the Anthropic Messages API and prompt-cache metadata.
HTTPS is required except for explicitly selected loopback endpoints. The HTTP
client refuses redirects so a response cannot forward the credential elsewhere.

Paths support `~` and environment variables. Source, output and cheatsheet paths
are below the selected repository. `--root` remaps those paths into an explicit
worktree, including paths originally configured as absolute paths below the
original repository. Output and source directories may not overlap. Source and
output file symlinks are refused.

`state_file` defaults to `output_directory/.translate_state.json`. It can be a
repository-relative cache or an explicitly selected external file. A cache can
be deleted safely: daily output ledgers are the durable record of completed
translation. Configuration and credential files cannot be overwritten as state
or cheatsheet output.

Only the named credential environment variable and file are considered. The
configured environment variable takes precedence. Omit `json_key` for a plain
text credential file; include it for one top-level JSON property. Missing
credentials fail by default. `api.required: false` permits an unconfigured
non-owner to report a skip; malformed selected credentials still fail. Legacy
`--credential-source` only asserts the configured kind and never enables
credential discovery or automatic provider switching.

Optional `prompts` keys `translate`, `classify` and `cheatsheet` override the
complete system-prompt strings. Text is used exactly as configured, including
leading and trailing whitespace. Generic built-in prompts are supplied when a
key is omitted. Translation returns an ordered JSON string array; classification
returns an ordered JSON array of integer `0` or `1` values.

Keep the existing `pipeline_revision`, filters, model choices and system prompts
when migrating an established archive. Increment the revision when intentionally
changing filtering or model instructions so prior decisions are not mistaken
for results from the new policy. Use `--force` when changing legacy per-source
output or explicitly requesting regeneration of previously accepted content.

Optional `generated_marker` is a comment **prefix**, such as
`<!-- Generated by example-command.`; it must not include a closing `-->`.
Keeping an existing prefix preserves its generated-file markers. Both renderer
and validator use the same configured marker.

Optional `pricing` maps exact model names, model families (`sonnet`, `opus`,
`haiku`) or `default` to `input`, `output`, `cache_write` and `cache_read` rates,
all in USD per million tokens. These are caller-supplied estimates, not current
price claims. Without rates, the runtime labels monetary estimates unavailable.

## Validation for repository checks

Explicit output paths use strict validation by default. To inspect all immediate
Markdown files in the configured output directory, excluding `README.md`, use:

```bash
scripts/validate --config /private/translation.json --root /work/task \
  --scan-output --format tsv
```

`--scan-output` cannot be combined with positional paths and does not recurse
into subdirectories. An empty output directory produces no findings after the
configuration has been validated; missing or invalid configuration still fails.
The configured output directory must exist and be a directory. A missing archive
can be skipped by the calling checker before invoking this command.
The command reads no credentials, calls no model, and writes no files.

`--format tsv` writes one `ERROR<TAB>message` line per finding to stdout, including
configuration failures. Tabs and newlines within messages are replaced with
spaces. Success has no output. The default format retains diagnostics on stderr.
Invalid CLI arguments use the normal argument-parser error and exit status.

An existing archive can explicitly select `--legacy-source-only` for a repository
inspection. Legacy files then need frontmatter and a `source` reference below
the configured source directory. The reference must end in `.md` and cannot
contain `..`; it may name an original file that has moved or no longer exists.
This mode does not check legacy generated markers, translation bodies or hashes.
It continues to reject output symlinks and files outside the selected output
directory. Daily filenames and `schema_version: 2` files still receive complete
ledger validation, so changing a legacy file to a daily format never bypasses it.

For asynchronous capture, `--allow-source-ahead` separately permits newer source
records. Neither inspection option replaces strict validation before publishing.
Keep any decision to skip an absent archive in the calling repository checker;
the validator always verifies its selected configuration when invoked.
